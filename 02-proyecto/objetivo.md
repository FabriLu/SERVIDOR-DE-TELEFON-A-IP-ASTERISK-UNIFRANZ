# Objetivo

Desplegar un servidor Asterisk en un contenedor Docker basado en Alpine Linux, configurar extensiones SIP, registrar al menos dos clientes y completar llamadas internas.

## Objetivos específicos
- Documentar host, red, SIP 5060 y rango RTP.
- Configurar extensiones de laboratorio sin credenciales personales o productivas.
- Verificar registro, llamadas, audio bidireccional y logs.
- Documentar resultados observados, evidencias e incidencias.

## Alcance
Base para una red local de laboratorio. Completar los datos del host y validar los ajustes según el entorno real.
